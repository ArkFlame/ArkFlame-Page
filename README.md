# ArkFlame Studios Local Preview

Open one of these:

1. Double-click `index.html`.
2. Or run a local server for the cleanest preview:

```bash
python3 preview-local.py
```

Windows:

```bat
start-local-preview.bat
```

Linux/macOS:

```bash
chmod +x start-local-preview.sh
./start-local-preview.sh
```

Then open:

```text
http://127.0.0.1:8000/
```

To publish, upload the folder contents to the site root.
